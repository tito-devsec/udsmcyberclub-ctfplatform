# Attack box artwork

- `terminal.svg`, `home.svg`, `image-viewer.svg`, `help.svg`, `science.svg`: icons of the Flat Remix
  Blue Dark theme as Kali Linux ships it (package `kali-themes-common`), by Daniel Ruiz de Alegría for
  Offensive Security, under the GNU GPL version 3 or later. They are used unchanged.
- `icons/`: more icons of the same theme and package, under the same licence and also unchanged: the
  folders and file types the file manager shows, the computer and its disk, the web browser, and the
  grey "symbolic" icons of toolbars and menus (back, forward, up, home, find, reload, add, close).
- `cyberchef.png`: CyberChef's own icon, from its release, by GCHQ under the Apache License 2.0.
- `wallpaper.webp`: drawn for UDSM CyberRange in the style of Kali's "cubes" wallpaper; it carries no
  Kali logo or name, which are trademarks of OffSec.
