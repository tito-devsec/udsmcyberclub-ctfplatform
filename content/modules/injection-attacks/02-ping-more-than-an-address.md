Start your machine and open the Ping Tool.

1. Ping `127.0.0.1` (your machine itself) and look at the output. This is what the tool is meant to do.
2. Now add a second command after the address, as in the lesson, and find out which user the tool runs as.
3. The flag is in `/flag.txt`. Read it the same way.

The machine has no internet access, so pinging websites outside it will fail. That is expected.
