Start your machine and open the club library. It lets you read members' notes in the browser.

The developers told us the notes are kept in the folder **`/app/books`** on the server. The flag is in **`/flag.txt`**, at the top of the file system.

1. Open a note and look at the address bar: how does the page say which file to open?
2. Work out how many levels up you need to go from `/app/books` to `/`.
3. Ask for the flag instead of a note.
